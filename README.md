# Symmetric configuration 93₁₀

Lean companion to John Tripodo’s *There is no symmetric configuration 93₁₀*.

The [original proof archive](https://github.com/jjtripodo-lgtm/symconf93-lean/tree/f0d8054c14bd20f5f42b4827a5c554be0b81aa72) contains the complete Lake project, version pins, and build and axiom-audit receipts. The original unrestricted theorem is `Symconf93.no_unrestricted_incidence93`.

The original archive is available under Apache-2.0.
