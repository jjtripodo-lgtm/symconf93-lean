# Lean companion for the symmetric configuration 93₁₀ paper

Download and extract [symconf-deficiency-two-lean.zip](symconf-deficiency-two-lean.zip).
The archive contains the original Lean 4 project, including the build and axiom-audit
receipt and the auxiliary results for orders 75 and 113 described in the manuscript.
Run the commands in the extracted project's README using its pinned toolchain.
